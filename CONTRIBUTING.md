# Contributing

Suggest a project or a correction through an issue or pull request. Include its official repository URL, a concise English description and a suitable category. State whether it is archived or requires an account, subscription or external service. Avoid credentials, personal configuration, affiliate links and copied upstream documentation.

For data changes, update catalog.json and catalog.csv, keep the README list consistent, then rebuild index.html with node build.cjs. Every repository should appear once in its primary category. Descriptions should explain what a project does without promising safety or compatibility.
